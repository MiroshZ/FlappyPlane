# FlappyPlane

Небольшая кооперативная 2D-игра на двоих на Python для macOS: самолёт пролетает через колонны, собирает монеты, зарабатывает валюту и открывает новые скины.

## Что внутри

- `pygame`
- запуск одной командой через существующий `.venv`
- полноэкранный режим
- главное меню
- магазин скинов за монеты
- пауза по `Esc`
- сохранение прогресса между запусками
- очки, лучший результат и collectible-монеты
- локальный онлайн на двоих в одной Wi-Fi сети

## Локальный онлайн по Wi-Fi

Оба ноутбука должны быть подключены к одной Wi-Fi сети. Один игрок запускает игру как хост, второй подключается к IP-адресу хоста.

На первом ноутбуке:

```bash
cd /Users/zakharmiroshnichenko/Documents/ДВФУ/Games_6sem
.venv/bin/python main.py --host
```

В терминале и в главном меню появится адрес вида `192.168.1.25:50007`. Запомни IP до двоеточия.

На втором ноутбуке:

```bash
cd /Users/zakharmiroshnichenko/Documents/ДВФУ/Games_6sem
.venv/bin/python main.py --join 192.168.1.25
```

Вместо `192.168.1.25` подставь IP, который показал хост. Если macOS спросит разрешение на входящие подключения, разреши его для Python.

По умолчанию используется UDP-порт `50007`. Если этот порт занят, можно выбрать другой одинаковый порт на обоих ноутбуках:

```bash
.venv/bin/python main.py --host --port 50008
.venv/bin/python main.py --join 192.168.1.25 --port 50008
```

## Управление

- `Enter` или `Space` в главном меню - начать забег
- `W` прыжок вверх для первого игрока
- `Arrow Up` прыжок вверх для второго игрока
- левая кнопка мыши
- `Esc` во время игры - пауза / продолжить

После проигрыша:

- `R`
- `Space`
- клик мышью

В магазине:

- клик по карточке скина - купить или надеть
- `Esc` или `M` - назад в меню

В локальном онлайне:

- хост играет за первого игрока
- клиент играет за второго игрока
- на клиенте можно нажимать `Space`, `W`, `Arrow Up` или кликать мышью для прыжка
- старт, рестарт, пауза и возврат в меню синхронизируются через хоста

## Структура

- `main.py` - точка входа
- `game/app.py` - состояния игры, меню, магазин, игровой цикл
- `game/entities.py` - самолёт, препятствия, облака, монеты
- `game/network.py` - локальный онлайн по UDP
- `game/settings.py` - настройки окна и баланса
- `game/save_data.py` - сохранение монет, рекорда и открытых скинов
